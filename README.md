# 🚀 OmniDoc — Intelligent Developer Documentation & Snippet Grid

**OmniDoc** is a smart, localized digital documentation workspace designed specifically for programmers to store, organize, and stress-test source code. Built to eliminate the visual clutter and human errors associated with traditional text editors, OmniDoc acts as an automated, high-visibility repository for critical development data.

## 🛠️ Run & Setup

```bash
python main.py
```
Then open `http://127.0.0.1:8000` in your web browser.

## ⚙️ Key Capabilities & Technical Features

* **Autonomous Language Parsing:** The application dynamically evaluates incoming source file extensions (such as `.py`, `.cpp`, `.java`, or `.sh`) to automatically generate and assign unified language classification badges without manual intervention.
* **Sequential Syntax Row-Structuring:** Raw text inputs are automatically split via newline matrices and wrapped into structured editor blocks, rendering clean line-by-line sequencing for maximum code readability.
* **High-Contrast Token Scanning:** OmniDoc scans line strings in real-time to locate developer tracking tags. It instantly highlights critical system `TODO` blocks in high-contrast orange to prevent developers from shipping unmapped bugs, while rendering foundational `NOTE` parameters in distinct blue block callouts.
* **De-Duplicated Storage Pipeline:** Optimized with an active upsert-verification workflow in the backend, the local database engine checks code strings against pre-existing data matrices, cleanly blocking accidental redundant entries and keeping memory tracking pristine.

## 🌍 Structural Value to Engineering

OmniDoc actively optimizes the software engineering cycle by acting as a safeguard against visual exhaustion and hidden code oversights. By highlighting developer action items across dense multi-runtime scripts, it protects live environments from running into production memory leaks or forgotten logic conditions—streamlining workflow speed for full-stack innovation.
